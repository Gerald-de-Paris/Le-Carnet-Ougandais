# Le Carnet Ougandais

Bilingual French-learning and Ugandan-culture publication. The public site is Astro; the learner application is Next.js in `apps/learn`.

- Public site: `npm install && npm run dev`
- Build: `npm run build`
- Learner app: `npm run dev:learn`
- Architecture: `MIGRATION-ROADMAP.md`

The public Astro migration is reviewed through PR #23; the separate Next.js learner app lives in `apps/learn`.
