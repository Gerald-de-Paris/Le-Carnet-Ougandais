# Learning Studio (Next.js)

The first learner-app foundation includes a 20-question A1 diagnostic in four difficulty stages, immediate explanations and three speaking missions.

Run locally: `npm install && npm run dev`.

Prototype boundaries: score is client-side only; no accounts, database, server-side attempts or cross-device progress are connected yet. Speaking missions are prompts, not automatic pronunciation grading.

Deploy as a separate Vercel project with Root Directory `apps/learn`.
